# Mapping Mangroves Using SAR

This project focuses on using Sentinel-1 SAR and Sentinel-2 optical data fusion to classify land cover in Ambanja Bay, Madagascar. The goal is to analyze changes in mangrove coverage over time and assess deforestation trends.

This work contributes to improving mangrove monitoring and supporting conservation efforts through remote sensing and GIS techniques.
## Objectives
- Classify land cover into mangroves, water, barren land, and non-mangrove areas.
- Assess deforestation trends in Ambanja Bay over time.
- Improve SAR-based mangrove mapping techniques.
- Contribute to conservation efforts through remote sensing and GIS analysis.
